 # Лабораторийн ажил 05

Энэхүү репозитор нь 05-р лабораторийн ажлын материал болон хэрэгжүүлэлтийг агуулна.

## Ажиллуулах

1. Репозиторыг татаж авна.
2. Шаардлагатай хамаарлуудыг суулгана.
3. Програмыг ажиллуулж, үр дүнг шалгана.

## Зорилго

Энэ лабораторийн ажлаар өгөгдсөн даалгаврыг хэрэгжүүлж, програмын ажиллагааг туршин баталгаажуулна.
